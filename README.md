## 📌 Pasos para Instalación / Ejecución

1. **Descargar el archivo:** Haz clic en el enlace de arriba para bajar el juego.
2. **Elegir la plataforma de ejecución:**
   - **En Teléfonos Móviles / Android:** Instala y ejecuta la aplicación directamente o utiliza tu instalador preferido.
   - **En PC / Otros dispositivos:** Puedes ejecutar el archivo mediante un emulador de **J2ME** (como *J2ME Loader*, *KEMulator*, o *SquirrelJME*).
3. **¡A jugar!** Configura los controles dentro del emulador o dispositivo y disfruta.
